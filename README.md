## 📂 Featured Projects

### 🏗️ (https://github.com/syedsameers/Azure-End-to-End-Project-Adventure-Work-Dataset) AdventureWorks: Azure End-to-End Data Engineering
**`Azure Data Factory` · `ADLS Gen2` · `Azure Databricks` · `PySpark` · `Microsoft Entra ID`**

A metadata-driven Azure pipeline built on the AdventureWorks dataset.

- 🔁 **Dynamic ingestion:** a parameter JSON drives an ADF **ForEach** loop with a parameterised **Copy** activity, pulling **10 CSV datasets** from GitHub (HTTP source) into the ADLS Gen2 **bronze** container
- 🔐 **Secure access:** Azure Databricks connects to the data lake through an **Entra ID service principal (OAuth)** instead of storage keys
- ⚙️ **Processing:** PySpark in Databricks for cleansing and transformation of the ingested data
- 📦 **Source data:** [Azure_end_2_end_project_dataset](https://github.com/syedsameers/Azure_end_2_end_project_dataset)

### 🛒 [E-Commerce Customer 360: Fabric Medallion Architecture](https://github.com/syedsameers/ecom-fabric-medallion-analytics)
**`Microsoft Fabric` · `ADLS Gen2` · `PySpark` · `Delta Lake` · `Direct Lake` · `Power BI`**

An end-to-end **Bronze → Silver → Gold** solution serving a unified Customer 360 model.

- 🏗️ **Pipeline:** ADLS Gen2 → Fabric Data Factory (ForEach) → Bronze → Silver → Gold → Direct Lake → Power BI
- ⚡ **PySpark transformations:** email cleaning, regex date standardisation, deduplication, 5-entity denormalisation
- 📊 **KPIs:** customer acquisition, revenue and AOV trends, order fulfilment, support and retention

### 🛡️ [Cyber Security Analytics: Microsoft Fabric & Power BI](https://github.com/syedsameers/cyber-security-fabric-analytics)
**`Fabric Lakehouse` · `Dataflow Gen2` · `OneLake` · `Direct Lake` · `SQL Server` · `Power BI`**

A hybrid analytics solution ingesting on-premises SQL Server records into a Fabric Lakehouse.

- 🏗️ **Architecture:** SQL Server → On-Premises Gateway → Dataflow Gen2 → OneLake → Direct Lake → Power BI
- 📐 **Star schema:** 6 dimension tables and 4 fact tables (incidents, firewall uptime, patch compliance, security posture)
- 📊 **KPIs:** incident volume and YoY trend, MTTR, threat actor attribution, attack vector distribution
